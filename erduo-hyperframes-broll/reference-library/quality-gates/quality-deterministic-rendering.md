# 质量门原子：确定性渲染

用途：保证同一输入、同一设计决策和同一素材在重复构建时得到稳定画面。

- 适用：相机抖动、粒子、随机列表、数字错峰、错位卡片、噪声纹理和任何看似随机的动效。
- 约束：所有随机性必须来自固定 seed、输入 hash 或镜头 index；不得使用当前时间、不可控全局随机或运行时外部状态。需要自然感时，用多频确定性函数替代真正随机。
- 验收：render receipt 记录 seed 派生方式；测试或 verify 可在相同输入下复查关键帧位置、元素顺序和运动结果一致。

外部吸收边界：吸收 video-shotcraft 的 no-runtime-random 规则，不复制 helper 实现。
