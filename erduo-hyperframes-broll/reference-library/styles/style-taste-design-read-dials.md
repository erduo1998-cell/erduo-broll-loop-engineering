# 风格原子：设计读数与三档拨盘

用途：在没有明确品牌 design 时，先建立一次设计读数，再把视觉差异、运动强度和信息密度变成可审核的创作参数。

- 适用：任何由 SRT 内容自行匹配风格的 B-roll 项目，尤其是用户没有提供截图、Logo、产品 CSS 或设计说明时。
- 约束：director 必须先写设计读数：内容类型、观众、情绪词、可信参考方向、禁用风格和素材条件。然后声明三个 1-10 档拨盘：视觉差异、运动强度、视觉密度。拨盘必须服务 SRT 语义，不得把默认紫蓝渐变、玻璃卡片、三等分卡片和满屏居中标题当通用答案。
- 验收：`reference_atom_trace` 记录读数、三档值、采用/拒绝理由。render 必须能说明色彩、字体、镜头密度、组件数量和动效强弱如何来自这些拨盘。

边界：这是 advisory atom。抽象吸收自 MIT 来源 `Leonxlnx/taste-skill` 的设计读数思想；不复制其完整 skill、代码或原始视觉。
