# B-roll director producer

1. Reject an invalid confirmed brief or deterministic preflight report. Read the [self-contained director method](../../references/director-method-contract.md), visual contract, [artifact manifest](../../references/artifact-manifest-contract.md) and [font assets](../../references/font-asset-contract.md). Do not preload unrelated reference bodies.
2. Execute `erduo-director-method-v1` directly: write the intent card, semantic map, evolving motif, density map, component/material taste audit and anti-fatigue audit before finalizing shots. SRT timing and the fixed material order `user-media → image-generation → Pexels → native auxiliary` are not negotiable.
3. Choose one primary visual direction and at most one compatible secondary direction. For every shot freeze semantic purpose, intended `hero_relation`, material roles, active route order, visible action, readable result state, transition intent, density, prohibited directions and reference trace. The plan must be concrete enough for a HyperFrames authoring child to create HTML, but must not over-freeze low-level HTML/CSS implementation fields that should be creatively solved by the official HyperFrames skill. Atom names or style prose alone are invalid; atom trace is advisory context, not a per-shot compliance template.
4. Plan local font files by role under the font-asset contract. When `assets/fonts/display-library.json` is present with its local `user-display/` binaries, choose exactly one `display_font_id` compatible with the primary visual DNA and freeze the complete `display_selection` object (ID, catalog/library identity, visual-DNA match, rejected alternatives and actual file hash). Bind it to every key quote, chapter focus, core number and emphasis node. This immutable object is a required downstream `displaySelection` input to master-build, not advisory prose. Information/technical faces may serve only supporting copy. Never propose network fonts, system stacks or silent fallback.
5. Freeze the complete director-method, plan, visual direction, type, density and trace artifacts in private storage. Also return a bounded path-free shot-plan fact packet for the main agent: compact shot table, design intent, font/display plan, material needs, prohibited directions, route counts and native-primary estimate. An external director enhancer is optional and may be consumed only with public source, pinned version and license evidence; record `{used:false}` when absent or unsuitable. Never require call transcripts or tool-event proof.
6. Run the method's deterministic completeness/route/font checks. Do not treat them as visual approval, route assets or dispatch another stage. The parent directly issues `shot_plan_review` from the bounded packet. On rejection, accept one aggregate revision packet and return one replacement plan; do not open reviewer or micro-fix contexts.
