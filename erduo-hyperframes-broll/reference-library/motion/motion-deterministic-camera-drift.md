# 动作原子：确定性相机漂移

用途：给页面、卡片、照片和空间镜头加入轻微手持感，同时保证重复渲染一致。

- 适用：静态截图、长停留卡片、轻微 2.5D 页面运镜、需要降低死板感的背景。
- 约束：抖动、漂移、粒子和随机排列必须来自固定 seed 或确定性函数；不得使用运行时 `Math.random()`、当前时间或不可复现外部状态。主信息阅读区间降低抖动幅度。
- 验收：render receipt 记录 seed 来源、漂移函数和最大位移；verify 或测试回放同一输入时关键帧位置稳定。

外部吸收边界：吸收 video-shotcraft 的确定性渲染和 handheld 语义，不复制源代码。
