# Runtime seek gate contract

`runtime-seek-gate` runs per block after source conformance. Its receipt phase
is `block`.

At entry, Action, Result, Hold, Exit and declared causal nodes, compare:

```text
fresh_direct(t)
zero_to_t(t)
end_to_t(t)
repeat_to_t(t)
```

Normalize text content, class list, computed display/visibility/opacity,
transform matrix, bounding boxes, z-index, SVG attributes, media time, loaded
font family/weight, primary-material consumer state, console failures and
network requests. All four paths must produce the same state hash.

`end_to_t` is mandatory because it exposes irreversible callbacks such as a
one-way `classList.add`. The gate also rejects Result visible before Action,
repeat-state drift and loaded-font drift.

No screenshots, contact sheet or visual-model request enters the receipt. A
PASS states seek determinism, not motion taste or animation quality. Every
receipt code must belong to the `runtime-seek-gate` policy registry.
