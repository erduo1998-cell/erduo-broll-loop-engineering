# 样式原子：产品设计令牌提取

用途：在制作产品、网页、工具或界面相关 B-roll 前，先从用户参考中提取可追溯的视觉语言。

- 适用：用户提供网页、截图、HTML/CSS、设计规范、产品 UI 或品牌参考。
- 约束：先记录字体族、字号层级、字重、主色、辅助色、圆角、边框、阴影、密度和主要运动气质；再决定画面样式。不能先选内部模板，再把用户参考染色。
- 验收：director receipt 写出 design token source、采用项、拒绝项和用户参考覆盖项；render receipt 的颜色、字体和运动 token 必须能回指这些来源或显式用户覆盖。

外部吸收边界：吸收 video-shotcraft 的“视觉语言从产品生长”方法，不复制其具体产品视觉、截图、代码或品牌资产。
