# Optional director enhancer contract

This compatibility layer is optional. The public production requirement is the self-contained [director method](director-method-contract.md), not an external Skill call.

When a user or host provides an installed director enhancer with a public source, pinned version and license, `broll-director` may consume its advice for intent, motif, rhythm, components, density or anti-repetition. Freeze only the enhancer identity/license metadata, output hash and the sections actually absorbed. Never copy or distribute its Skill source, prompts, private paths or transcript.

The director must still independently produce the complete
`erduo-director-method-v1` artifact. It must preserve SRT timing, this
product's material order, local font rules, visual DNA, artifact isolation and
the deterministic director facts boundary. Enhancer word-count timing,
prohibited Pexels/generated media, proprietary output files or generic scene
tables are ignored. An enhancer cannot create `shot_plan_review` or claim
visual approval before source exists.

Missing, unlicensed, unavailable or failed enhancers result in `{used: false}` and normal self-contained direction. They are never startup, production, validation or release blockers. No invocation evidence, transcript hash, tool-call proof or `required_skill` field is part of the public contract.
