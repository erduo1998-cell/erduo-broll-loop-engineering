# video-shotcraft 样式：Typography Card Atomic Rules

来源：video-shotcraft 批量审计的脱敏抽象原子。具体证据见 handoff/VIDEO-SHOTCRAFT-*.json；本文件不复制 Remotion TSX、示例素材或音频。

- 用途：Per-card extraction of typography shot parameter atoms. Each card has defined: intent, motion core, parameter table with typical values and tuning手感, known pitfalls, sound dependency, and reference implementation path.

边界：这是 advisory atom。用户 design、真实素材、当期语义优先；采用或拒绝都必须写入 reference_atom_trace。
