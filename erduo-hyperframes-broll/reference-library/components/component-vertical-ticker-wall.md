# 组件原子：纵向列表墙

用途：用多列纵向循环列表表达大量案例、证据、关键词或选择项，作为背景信息密度。

- 适用：旁白在讲“很多”“持续出现”“批量案例”“生态流动”这类语义。
- 约束：ticker 是背景或次焦点；主句阅读期间降低速度、对比和运动面积。列表内容必须来自本期语义或用户素材，不填无意义占位词。
- 验收：receipt 记录列表来源、列数、循环周期、遮罩区域和主信息避让区；pixel gate 与主 agent 检查相邻镜头没有连续复用同一滚动墙当主视觉，verify 只验证其 receipt 与 render manifest/hash 链。

外部吸收边界：吸收 video-shotcraft VerticalTicker 的组件语义，不复制 Remotion 代码。
