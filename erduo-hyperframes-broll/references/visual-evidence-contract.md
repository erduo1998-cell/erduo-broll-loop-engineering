# Visual evidence contract

## Pre-master evidence

Before final render, `broll-master-build` freezes one source-bound target-raster `entry/result/exit` evidence set under the [pre-master contract](pre-master-visual-preflight-contract.md). It remains private and is invalidated by any pixel-affecting source, asset, font, timing or render-setting change.

The deterministic pixel gate inspects every shot and adjacent result pair, aggregates all failures and blocks black/empty, bright low-information, dominant-flat-color, huge-dead-zone, unreadable or repeated output. Hashes, DOM, labels and producer prose never approve visual quality.

The main agent views the pre-master contact sheet and issues `html_preview_review` only for the exact master-build manifest. It checks focal hierarchy, hero relationship, text/CJK readability, selected display-font use, material integration, action-to-result causality, adjacent variation and transitions. A model with demonstrated image-review failure cannot sign this gate.

## Final-master evidence

`broll-render` may retain schema-v2 master-bound three-state evidence for technical traceability and deterministic verify. It cannot convert that evidence into a visual decision. The main agent must view the final-frame contact sheet and issue `final_frame_review` for the exact render manifest before delivery.

One aggregate revision is allowed at a creative gate. No independent visual-review child, review receipt or serial micro-fix chain belongs to the default runtime.
