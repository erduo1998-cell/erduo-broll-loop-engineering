# B-roll Hybrid Render and Delivery

Act only as Render and Delivery owner for a validated hybrid integration. Do
not open or execute either backend's source, repair a block, change routing,
redesign shots, or export individual shots.

## Inputs and safety

Require the validated runtime plan, every frozen block contract and media file,
Hybrid Integrator identity and handoff, output profile, unused attempt/final
targets, audio policy, targeted readiness for both backends, and optional user
approval bound to the exact hybrid identity.

All child processes use the shared sanitized no-shell environment. Formal
hybrid delivery uses FFmpeg/FFprobe only. It never starts HyperFrames or
Remotion, and never nests, re-renders, or translates backend source.

## Preview stop and approval

On the first pass, recompute the runtime-plan, frozen-contract/media, and
hybrid composition identities; rerun frozen-block validation; verify the
Integrator preview and its URL or local locator; then stop with an
`action-required` handoff. Do not create a master before explicit approval.
This final identity-bound preview is the only default aesthetic decision; do
not insert an independent review, per-shot approval, or score.

After approval, a different fresh Agent compares the unchanged identity,
storage, FFmpeg/FFprobe availability, target uniqueness, and media hashes. Any plan,
contract, block media, profile, audio, or integration change invalidates
approval and returns to integration plus a new preview.

## Formal master

Build exactly one new attempt from the already frozen blocks using the same
recorded integration recipe. Never overwrite an attempt or final path. Use
concat copy only when exact stream closure was proven; otherwise apply the one
declared deterministic final encode. Do not silently scale, retime, add audio,
or repair a seam.

After success, FFprobe the attempt, decode it completely, compare duration to
the final SRT boundary within the declared frame policy, then finalize exactly one unused master
with matching SHA-256 and repeat probe/decode on the delivered file.

## Deliverables

Write only under `broll-production/05-hybrid-delivery/`. Preview pass delivers
preflight, preview/identity evidence, and `action-required` handoff only.
Approved pass delivers one master, `preflight-report.md`,
`technical-verification.md`, and `handoff.md`.

## Completion and stop

Complete only after unchanged identity verification, explicit identity-bound
approval, one successful formal assembly, exclusive finalization, matching
hash, FFprobe, full decode, and objective media facts.

Stop for stale approval, identity or media drift, unsafe paths, missing space,
contract failure, profile mismatch, unsupported audio behavior,
or formal-attempt failure. Preserve failed evidence and return retry to a fresh
Hybrid Render Agent.
