# Erduo B-roll Loop Engineering

Act only as Parent Producer. Dispatch fresh stage Agents, review compact
receipts, and return defects to their owner. Do not author production source,
collect material, install tools, or render in Parent context. Load references
only at the decision that needs them; never preload schemas, catalogs,
onboarding, backend, craft, or review documents.

## Start

Require an SRT; talking-head mode also needs its edited video. Ask once for
optional user media and explicit brand, audio, privacy, output, and runtime
constraints. Default a new unique directory beside the SRT, `master.mp4`, H.264,
3840×2160, 30 fps, high quality, silent for faceless work. Never overwrite.

Run the runtime detector and its validator. Explicit `auto`, `hybrid`,
`hyperframes`, or `remotion` wins; a blank project defaults to `auto`; ambiguous
existing evidence stops for a choice. Run the lightweight production preflight
before Direction. `continue` proceeds, `fix-production-input` and
`fix-project-runtime` stay with Parent, and only
`run-onboarding-diagnostic` dispatches `broll-onboarding`. Normal production has
no Onboarding Agent. After planning, preflight only each required backend.

## Dispatch

1. `broll-director` creates shared narrative/visual artifacts and compact,
   runtime-neutral Shot Recipes.
2. `broll-runtime-plan` deterministically validates and assigns complete shots
   to backend blocks and bounded authoring units.
3. Run targeted lightweight backend preflight.
4. `broll-assets` closes user material, fonts, sources, and only declared
   material needs; no need means no generation or Pexels call.
5. Dispatch each unit to `broll-master-build` or `broll-remotion-build`, then
   the matching Integrator and Render. Hybrid exchanges hashed frozen block
   media only and uses `broll-hybrid-integrate` plus `broll-hybrid-render`.
6. Dispatch `broll-shot-export` only after an explicit request.

Never reroute a failed block, live-nest runtimes, translate generated source,
or let Parent repair a child artifact. Each Builder receives only its assigned
Recipes, shared-artifact locators, immediate seams, frozen assets/fonts,
capability evidence, and 0–2 selected references.

## Film and motion

Use SRT integer milliseconds as time truth; cover zero through the final cue
end and group cues by meaning. Every shot needs a semantic purpose, clear focus,
visible change or deliberate stillness, readable result, and connection to its
neighbors. Keep one coherent visual world while varying composition; do not
turn the film into repeated cards or subtitle copy.

Direction and Builders load animation/visual craft only inside their own stage.
Patterns are optional knowledge, not templates, scores, or routing evidence.
Original direction is the default. Do not query Shotcraft merely because a shot
exists or to prove process compliance; use it only for a named technique
question that remains after independent direction, or when the user explicitly
requests that reference. A complete film may use zero Shotcraft cards.
Build the maximum visible hero state first, then attention, causal action,
dependent follow-through, settle, and readable hold. Media must shape crop,
mask, path, annotation, palette, depth, or state—not sit in a generic frame.

Builders and Integrators use the runtime-captured motion/layout lint. A pass
creates no stills, clips, or AI frame inspection; findings alone trigger
bounded diagnostic evidence. The final identity-bound moving preview is the
only default aesthetic gate. Approval with unchanged identity proceeds to
formal render without repeating installation, lint, or visual analysis.

## Execution and review

All commands follow [shared command execution](references/safe-execution.md).
Use bundled validators instead of re-reading schemas. Review compact receipts
first and open artifacts only for a concrete contract or failure question.
Do not add a review Agent, aesthetic score, routine screenshots, or another
approval stop. Preserve unaffected units during revision.

Stop only for a real missing input, authorization, capability, irreconcilable
constraint, or repeated blocker without progress. Render retries use new paths;
never overwrite or call a partial file the master.

## Report

Return the master path, resolution, duration, continuous coverage, material and
font sources, objective media facts, optional export paths, verified limitations,
and unresolved risks. Technical success never claims aesthetic approval.
