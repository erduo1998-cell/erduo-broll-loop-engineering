# 样式原子：文字入场与停留预算

用途：让标题、短句、标签和数字在动效后可读，而不是刚出现就切走。

- 适用：文字是镜头主信息、解释标签、数字结果或章节转折。
- 约束：每个文字镜头声明 reveal mode、入场帧数、错峰规则、落字后停留帧数和出场方式；全片主标题入场技法最多两种。短句优先完整停留，长句优先拆行，不用高频闪烁弥补信息过载。
- 验收：pixel gate 与主 agent 检查文字落定后的可读区间；如果镜头时长不足以完成入场加停留，director 必须合并、删字或换成非文字表达。verify 不得替代该画面判断。

外部吸收边界：吸收 video-shotcraft 的标题入场和可读停留规则，不复制 Remotion 文本动画实现。
