# Black light-pass composition contract

`buildLightPassComposition()` is the supplementary soft-light route: it uses the shared global timeline and a fingerprinted effect document, but it does not become a primary coverage type. It creates high-quality H.264 MP4 with an opaque black root and may contain glow, flare, or particles only for filter/lighten-style compositing in the editor.

The builder excludes Alpha output, subtitles, BGM, narrative text, URLs, paths, and credentials. Validation requires an ordinary non-alpha pixel format plus real frames that retain a near-black base and nonzero illuminated pixels; an MP4 extension or a black thumbnail is insufficient proof.
