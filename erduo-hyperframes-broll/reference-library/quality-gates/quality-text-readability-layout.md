# 质量门原子：运动文字与布局可读性

用途：防止文字、页面和 UI 在运动、缩放、透视或叠加中变得不可读。

- 适用：所有文字主信息、数字主信息、页面截图、3D/2.5D 运镜和列表墙。
- 约束：主文字落定后必须有稳定可读区间；页面截图不可只靠低分辨率贴图放大；3D 透视不能让关键文字倾斜到难以辨认；叠加元素必须落入真实布局槽位或明确说明为概念化组件。
- 验收：render 冻结文字落定、结果和退出证据；pixel gate 与主 agent 实际检查，任一关键文字或目标 UI 状态不可辨认则失败。verify 只核验 main review ref 绑定，不得自行作视觉批准。

外部吸收边界：吸收 video-shotcraft 的截图清晰度、3D 文字和布局完整性质量门，不复制判例原文或代码。
