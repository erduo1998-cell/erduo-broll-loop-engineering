# video-shotcraft 卡片族：活体图表：数据不是插图是剧情，图表自身承载叙事推进

来源：video-shotcraft 批量审计的脱敏抽象原子。具体证据见 handoff/VIDEO-SHOTCRAFT-*.json；本文件不复制 Remotion TSX、示例素材或音频。

- 用途：活体图表：数据不是插图是剧情，图表自身承载叙事推进
- 约束：必须真图表语境（真轴标/真数据/真文案），灰阶版全裁；每种活体动作（尖峰/重标/迁徙）全片 ≤1 次；数据结尾必须真静止 ≥36f；强调色标事件/主角，全灰读不出重点
- 验收：收据记录数据真语境检查、活体动作次数、静止帧数
- HyperFrames 改写：adapted
- 覆盖卡片：chart-live-moves、gauge-readout-moves、dataviz-landscape-open
- 参考 demo：demos/chart-live-moves/OscilloscopeStreamV2.tsx、demos/chart-live-moves/UnitDotSwarmRegroupV2.tsx、demos/chart-live-moves/AxisRescaleShockV2.tsx、demos/gauge-readout-moves/
