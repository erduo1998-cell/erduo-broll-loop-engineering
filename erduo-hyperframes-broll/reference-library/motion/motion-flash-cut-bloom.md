# 动作原子：闪白光感转场

用途：在明确冲击、反转、结果揭示或章节换挡时，用短促光感遮蔽硬切。

- 适用：相邻镜头存在明显能量上扬、语义翻页或视觉空间跳转。
- 约束：闪光必须短、峰值明确、首尾帧都有真实内容；不得连续使用造成白屏感。暖白、径向和亮度峰值都要服务内容节点。
- 验收：render evidence 写出转场窗口、峰值帧和遮蔽层；pixel gate 与主 agent 检查转场前后画面非空且闪光没有吞掉主文字落点，verify 只验证 evidence/receipt 哈希绑定。

外部吸收边界：吸收 video-shotcraft FlashCut 的转场语义，不复制 Remotion 实现。
